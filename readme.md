## Лабораторная работа №2: исходный код

Исходные тексты расположены в [`lab_02/riscv-lab/src`](lab_02/riscv-lab/src):

- `main.s` — исходная программа RV32I, проходящая по массиву из девяти 32-битных чисел и сохраняющая максимум в `x31`;
- `main_opt.s` — её оптимизированный вариант: инкремент указателя перенесён сразу после загрузки, а перед сравнением добавлен `nop`, что устраняет конфликт загрузки и использования данных в конвейере;
- `link.ld` — скрипт компоновщика;
- `Makefile` — сборка образа в формате `.hex`.

По данным отчёта, оптимизация сократила трассу выполнения на 10 тактов (около 15 %).
